🗂️ Weekly Session Guide — Hour-by-Hour Plan

Important: B.Com(Hons) Semester 1 has no certification/mock-test component for students. This guide is built around exactly 2 Shadow Projects: P1 from Weeks 1–6 and P2 from Weeks 7–12.

📅 Week 1 — P1 Phase 1: Company Selection + Accounting Setup

3 Hours · B.Com(Hons) Sem 1
Time BlockFaculty ActionStudent Activity
Hr 1 · 0:00–1:00
🎙️ Concept + Demo
  • Introduce Tata Group, annual report structure and accounting statement sections.
✏️ Student Task
  • Select Tata company, create Drive folder and write company profile.
Hr 2 · 1:00–2:00
💻 Guided Lab / Tool Demo
  • Show Excel, ChatGPT/Gemini, Copilot or Grammarly workflow according to this week's task.
🛠️ Hands-on Lab Work
  • Complete weekly worksheet / Excel work / report section and save evidence in Google Drive.
Hr 3 · 2:00–3:00
✅ Review + Upload Checkpoint
  • Review student work, clarify doubts and explain upload requirements. No certification/mock activity for students in Sem 1.
📤 Submission + Reflection
  • Upload weekly file and write 5-line reflection on manual work vs AI support.
