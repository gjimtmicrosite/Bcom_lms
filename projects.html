📁 4 Benchmarked Shadow Projects — BCom Sem 1

These commerce-focused projects combine accounting, finance, taxation, analytics, and AI tools. Students must complete manual work before AI-assisted phases.

P1: Retail Store Analysis P2: GST & Billing P3: Startup Finance P4: Financial Dashboard

🛒 P1: Retail Store Business Analysis DMart / Reliance Smart Weeks 1–3

Objective: Analyse the pricing, sales strategy, and customer trends of a retail business.

📋 4-Phase Framework

🔵 Phase 1 — Business Understanding
  • Select a retail chain: DMart or Reliance Smart
  • Study product categories, offers, customer segments
  • Visit store physically or online and record observations
  • Create handwritten notes of store operations
🟠 Phase 2 — Manual Data Collection
  • Collect prices of 20 products
  • Compare pricing with competitors
  • Calculate estimated daily revenue manually
  • Create Excel sheet with product data
🤖 Phase 3 — AI Analysis
  • Use ChatGPT for customer trend analysis
  • Use Excel AI for sales forecasting
  • Create charts for revenue and demand
  • Generate insights report using AI
🟢 Phase 4 — Presentation & Viva
  • Create 5-slide presentation
  • Present findings with AI insights
  • Submit Excel file and reflection note

📊 Evaluation Rubric

CriteriaWeightFocus
Business Understanding30%Retail model and pricing strategy
Data Analysis30%Accuracy of calculations and comparisons
AI Integration40%Charts, insights, and AI reflection

🧾 P2: GST Billing & Invoice Management GST Portal Weeks 4–6

Objective: Understand GST calculation, invoice creation, and taxation workflow.

📋 4-Phase Framework

🔵 Phase 1 — GST Basics
  • Study CGST, SGST, IGST concepts
  • Learn GST invoice structure
  • Create handwritten GST notes
🟠 Phase 2 — Invoice Preparation
  • Create 10 manual invoices
  • Calculate GST amounts manually
  • Prepare sales and purchase registers
🤖 Phase 3 — AI Accounting Support
  • Use Excel AI for automated GST summaries
  • Use ChatGPT for GST error checking
  • Create GST analysis dashboard
🟢 Phase 4 — Reporting
  • Generate GST return summary
  • Present tax analysis report
  • Submit Excel workbook

🚀 P3: Startup Financial Feasibility Indian Startup Study Weeks 7–9

Objective: Analyse startup revenue, costs, funding, and profitability.

📋 4-Phase Framework

🔵 Phase 1 — Startup Research
  • Select one Indian startup
  • Study revenue model and funding
  • Prepare startup profile
🟠 Phase 2 — Manual Financial Analysis
  • Estimate revenue and expenses
  • Create break-even analysis
  • Prepare cost sheet
🤖 Phase 3 — AI Financial Modelling
  • Use ChatGPT for investment analysis
  • Use Excel AI for projections
  • Create profitability scenarios
🟢 Phase 4 — Investor Presentation
  • Create startup financial presentation
  • Submit financial model
  • Present findings in viva

📊 P4: Financial Dashboard Creation Excel / Power BI Weeks 10–12

Objective: Build financial dashboards using accounting and sales data.

📋 4-Phase Framework

🔵 Phase 1 — KPI Selection
  • Select accounting KPIs
  • Design dashboard structure
  • Create manual calculations
🟠 Phase 2 — Data Cleaning
  • Clean Excel dataset
  • Create pivot tables
  • Validate formulas manually
🤖 Phase 3 — Dashboard Building
  • Use Power BI / Excel AI
  • Create KPI cards and charts
  • Generate AI insights
🟢 Phase 4 — Executive Reporting
  • Present dashboard to faculty
  • Submit dashboard file
  • Write AI reflection note
